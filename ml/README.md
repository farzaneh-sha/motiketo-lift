# ML — Behavioral Profiling

This folder contains the machine learning work behind the app's behavioral profiling
feature: a K-Means model that clusters a user's 10 questionnaire answers into a
behavioral pattern (`lower_concern` / `higher_concern`), used to personalize
motivational messaging. It is **not** a clinical or diagnostic tool.

## Layout

- **`data/`** — training dataset (`Dataset_Eating_Disorder.csv`).

- **`notebooks/`** — the current, numbered pipeline (data prep → model/question
  selection → cluster profiling → production packaging). Run in order to
  reproduce the model from scratch.

- **`production/`** — the trained model artifact (`behavioral_kmeans_v1.joblib`)
  and its metadata contract (`behavioral_model_metadata_v1.json`), generated by
  `notebooks/04_production_inference_and_packaging.ipynb`. See its own README
  for details.

- **`src/behavioral_model/`** — the Python package the backend imports for
  inference. It only loads the artifacts in `production/`; it never trains a
  model or touches the raw CSV.
