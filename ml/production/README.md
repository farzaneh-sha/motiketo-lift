# Behavioral Profiling Production Files

- `behavioral_kmeans_v1.joblib` contains the trained two-cluster K-Means model.
- `behavioral_model_metadata_v1.json` contains the runtime contract: feature order, ordinal mappings, semantic labels, cluster centers, and production thresholds.

Both files are generated by `ml/notebooks/04_production_inference_and_packaging.ipynb`.

The Backend loads them through `ml/src/behavioral_model`. Both files are required for inference. The semantic labels describe relative behavioral patterns and are not medical diagnoses.
